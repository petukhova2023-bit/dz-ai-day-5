## 2. Цепочки взаимодействия по типовым задачам

### Цепочка 1: Маркетинговый запуск рекламной кампании
```
Владелец системы
  → [[alex|Алекс — Chief of Staff]] (постановка задачи)
    → [[research-agent|Research Agent]] (анализ рынка и конкурентов)
    → [[cmo|CMO]] (стратегия и сообщения)
    → [[ads-manager|Ads Manager]] (кампания и креативы)
    → [[kira|Кира — Brand Designer]] (визуал креативов)
    → [[seo-specialist|SEO Specialist]] (если нужна посадочная)
  → [[alex|Алекс — Chief of Staff]] (сборка пакета на согласование)
  → [[data-analyst|Data Analyst]] (после запуска: метрики и выводы)
```

### Цепочка 2: B2B-сделка по техническому оборудованию
```
Лид
  → [[tim|Тим — Sales Lead]] (квалификация, КП, переговоры)
    → [[lera|Лера — Legal]] (договор и спецификация)
    → [[pasha|Паша — Procurement Lead]] (закупка под сделку)
    → [[denis|Денис — Logistics Lead]] (отгрузка и логистика)
    → [[sveta|Света — CFO]] (контроль маржи и дебиторки)
    → [[anya|Аня — Bookkeeper]] (закрывающие документы)
  → [[alex|Алекс — Chief of Staff]] (отчёт о завершении сделки)
```

### Цепочка 3: Тендер
```
[[mira|Мира — Tender Specialist]] (поиск тендера, анализ)
  → [[lera|Лера — Legal]] (документация и обеспечение)
  → [[tim|Тим — Sales Lead]] (коммерческое предложение)
  → [[sveta|Света — CFO]] (расчёт маржи и финансовых рисков)
  → [[pasha|Паша — Procurement Lead]] (проверка возможности поставки)
  → [[alex|Алекс — Chief of Staff]] (согласование с владельцем системы)
```

### Цепочка 4: Контент личного бренда
```
Владелец системы
  → [[sofya|Софья — Personal Brand Lead]] (тема, формат, черновик)
    → [[research-agent|Research Agent]] (фоновое исследование)
    → [[kira|Кира — Brand Designer]] (визуал для презентации/reels)
  → [[community-manager|Community Manager]] (запуск, реакции, обратная связь)
  → [[alex|Алекс — Chief of Staff]] (отчёт по результатам)
```

### Цепочка 5: Финансовая сводка и операционка
```
[[anya|Аня — Bookkeeper]] (первичка, акты)
  → [[sveta|Света — CFO]] (управленческая аналитика, маржа, cash flow)
  → [[nikita|Никита — Operations Lead]] (контроль дедлайнов и платежей)
  → [[alex|Алекс — Chief of Staff]] (недельный дайджест)
```

### Цепочка 6: Разработка продукта (приложение / лендинг)
```
[[product-manager|Product Manager]] (требования, MVP)
  → [[research-agent|Research Agent]] (аудитория и конкуренты)
  → [[cto|CTO]] (архитектура)
  → [[frontend-engineer|Frontend Engineer]] + [[backend-engineer|Backend Engineer]] (разработка)
  → [[qa-engineer|QA Engineer]] (тестирование)
  → [[devops-engineer|DevOps Engineer]] (деплой)
  → [[cmo|CMO]] + [[ads-manager|Ads Manager]] (запуск)
  → [[data-analyst|Data Analyst]] (метрики)
  → [[community-manager|Community Manager]] (обратная связь)
  → [[alex|Алекс — Chief of Staff]] (дайджест)
```

### Цепочка 7: E-commerce бутик
```
[[natasha|Наташа — E-commerce Lead]] (ассортимент, товарная экономика)
  → [[pasha|Паша — Procurement Lead]] (закупки)
  → [[denis|Денис — Logistics Lead]] (склад, маркетплейсы, доставка)
  → [[lera|Лера — Legal]] (договоры с маркетплейсами)
  → [[kira|Кира — Brand Designer]] (карточки товаров и креативы)
  → [[seo-specialist|SEO Specialist]] (оптимизация на маркетплейсах)
  → [[sveta|Света — CFO]] (товарная маржа)
  → [[alex|Алекс — Chief of Staff]] (дайджест)
```

### Цепочка 8: Управление календарём владельца системы
```
Владелец системы / внешние запросы
  → [[dasha|Даша — Personal Assistant]] (триаж, календарь, подготовка к встречам)
    → [[sofya|Софья — Personal Brand Lead]] (логистика выступлений)
    → [[nikita|Никита — Operations Lead]] (стыковка с операционными дедлайнами)
  → [[alex|Алекс — Chief of Staff]] (общая загрузка)
```
