# Backend Engineer — Серверная часть

## Роль
Отвечает за API, хранение данных, бизнес-логику, авторизацию и интеграции приложения.

## Зона ответственности
- Backend API.
- База данных и модели данных.
- Авторизация и права доступа.
- Интеграции с внешними сервисами.
- Производительность и обработка ошибок.
