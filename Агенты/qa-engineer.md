# QA Engineer — Контроль качества

## Роль
Проверяет, что продукт работает по пользовательским сценариям, не ломается при изменениях и соответствует требованиям.

## Зона ответственности
- Тест-кейсы.
- Проверка ключевых сценариев.
- Баг-репорты.
- Регрессионное тестирование.
- Финальный чек перед релизом.
