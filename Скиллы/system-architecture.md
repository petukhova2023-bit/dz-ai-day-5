# system-architecture

## Когда использовать
- Нужно выбрать техническую архитектуру.
- Нужно разделить frontend/backend/интеграции.
- Нужно оценить технический риск.
- Нужно описать систему перед разработкой.

## Workflow
1. Прочитать цель продукта и ограничения.
2. Определить основные модули.
3. Описать потоки данных.
4. Зафиксировать API-контракты и границы.
5. Выдать решение с рисками и следующим шагом.

## Выход
Короткая схема архитектуры, список модулей, риски, открытые вопросы.
