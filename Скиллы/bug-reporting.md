# bug-reporting

## Когда использовать
- Найдена ошибка.
- Нужно передать баг разработчику.
- Нужно отделить симптом от причины.

## Workflow
1. Описать окружение.
2. Дать шаги воспроизведения.
3. Указать ожидаемый и фактический результат.
4. Добавить приоритет и владельца.

## Выход
Короткий баг-репорт, понятный разработчику.
