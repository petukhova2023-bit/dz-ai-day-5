# user-scenarios

## Когда использовать
- Нужно описать путь пользователя.
- Нужно проверить UX.
- Нужно дать QA сценарии тестирования.

## Workflow
1. Определить пользователя и цель.
2. Описать шаги от входа до результата.
3. Указать возможные ошибки и пустые состояния.
4. Добавить критерии успешного завершения.

## Выход
User flow, happy path, edge cases, acceptance criteria.
