# weekly-digest

Сборка единой пятничной сводки по всем направлениям бизнеса.

## Когда использовать

- Каждую пятницу 18:00 — автоматический weekly digest
- По запросу «дай сводку недели»
- Перед ключевыми планёрками
- Перед стратегической встречей с владельцем системы

## Источники данных

- `.claude/knowledge-base/tasks/active.md` — активные задачи
- `.claude/knowledge-base/tasks/archive.md` — закрытые задачи недели
- Отчёты агентов (если есть в `.claude/knowledge-base/reports/`)
- Запросы агентов через Agent tool — кратко по их зонам

## Структура digest

```markdown
# Сводка недели · <дата>

## Главное

<3-5 строк итога недели одним абзацем>

---

## Деньги (Света)

- Cash flow: <начало → конец недели>
- Поступления: <сумма>
- Списания: <сумма>
- Дебиторка: <общая, просроченная, динамика>
- Кассовые разрывы на следующую неделю: <да/нет, даты>

RED FLAG: <если есть критичное>

---

## Продажи B2B (Тим)

- Выставлено счетов: <N на сумму X>
- Оплачено: <N на сумму Y>
- Конверсия счёт→оплата: <%>
- Зависшие сделки > 14 дней: <N>
- Топ-3 сделки в работе: <список>

---

## Личный бренд (Софья)

- Выпущено постов / Reels: <N>
- Прирост подписчиков: <±N>
- Топ-вовлечение: <какой пост / Reels>
- Запросы на выступления: <N>

---

## E-commerce бутик (Наташа)

- Выручка недели: <сумма>
- Новых клиентов: <N>
- Топ-категории: <2-3>
- Запасы тревоги: <если что-то «зависает»>

---

## Тендеры (Мира)

- Найдено: <N>
- Подали: <N>
- Выиграли: <N на сумму X>
- Проиграли: <N> (причины)

---

## HR (Оля)

- Открыто вакансий: <N>
- Кандидатов в воронке: <N>
- Шорт-лист: <N>
- Выходов: <N>

---

## Операционка (Никита)

- Закрыто задач: <N>
- В работе: <N>
- Просрочено: <N>
- Зависло: <N> (причины)

---

## Приоритеты следующей недели

1. <P0 задача>
2. <P0 или P1 задача>
3. <P1 задача>

---

## Красные флаги

<если есть критичное на следующую неделю>
```

## Workflow сборки

1. Прочитать `.claude/knowledge-base/tasks/active.md` и `archive.md` за период недели
2. Через Agent tool опросить ключевых агентов параллельно (Алекс, Тим, Света, Софья, Наташа, Мира, Оля, Никита)
3. Каждому одна задача: «Дай 5–7 строк по своему направлению за период X–Y»
4. Собрать ответы в шаблон выше
5. Положить файл в `.claude/knowledge-base/reports/week-<номер>-<год>.md`
6. Дать краткую выжимку владельцу системы — 5 строк, не больше

## Тон

- Цифры > эмоции
- Факты > предположения
- Красные флаги — отдельной секцией, не размазывать
- Без инфобиз-лексики, без «круто» / «супер» / «отлично»

## Антипаттерны

- Не делать сводку если у агентов нет данных — лучше пустой блок с пометкой «нет данных»
- Не врать если что-то не сделано — честно отметить
- Не превращать в простыню — владелец системы не будет читать 10 страниц
- Не дублировать информацию из агентских отчётов — это aggregation
