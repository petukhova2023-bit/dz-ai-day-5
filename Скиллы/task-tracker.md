# task-tracker

Скилл операционного контроля задач и дедлайнов. Не даёт задачам «рассосаться».

## Когда использовать

- После любой встречи с владельцем системы — зафиксировать договорённости
- Каждое утро — проверить что просрочено
- Каждую пятницу — недельный отчёт по исполнению
- При запросе «что висит / что не сделано»

## Структура хранения

Все задачи — в файле: `.claude/knowledge-base/tasks/active.md`
Архив выполненных: `.claude/knowledge-base/tasks/archive.md`

Формат записи:
```markdown
## Задача: <название>
- **Owner**: <агент или человек>
- **Создана**: YYYY-MM-DD
- **Дедлайн**: YYYY-MM-DD
- **Приоритет**: P0/P1/P2/P3
- **Статус**: in_progress / blocked / done
- **Контекст**: что именно нужно сделать
- **Зависимости**: что ждём
- **Last update**: что произошло последнее
```

## Workflow

### Фиксация задачи
1. Прочитать `.claude/knowledge-base/tasks/active.md`
2. Добавить новую задачу в формате выше
3. Если дедлайн < 24ч — отметить P0
4. Если задача от владельца системы без срока — поставить P1, дедлайн 3 рабочих дня

### Утренний check (ежедневно)
1. Прочитать active.md
2. Найти все задачи с дедлайном <= сегодня
3. Найти все задачи в blocked статусе > 2 дней
4. Сформировать сводку:
   ```
   СЕГОДНЯ ГОРИТ: <список>
   ЗАВИСЛО: <список с причинами>
   В РАБОТЕ: <количество>
   ```

### Эскалация
- Если задача просрочена > 1 дня и owner молчит — спросить у owner'а статус
- Если просрочка > 3 дней — эскалация Алексу
- Если задача P0 не двигается > 4 часа — пинг владельцу системы

### Закрытие задачи
1. Переместить из active.md в archive.md
2. Отметить дату закрытия
3. Если результат был неудачным — пометить и оставить в archive.md как урок

## Weekly digest (пятница 18:00)

```
СВОДКА НЕДЕЛИ
Закрыто: <N задач>
В работе: <N задач>
Просрочено: <N задач> (детализация)
По агентам: <Тим: X, Света: Y, ...>
Приоритеты на следующую неделю: <топ-5>
```

## Антипаттерны

- Не фиксировать задачи без owner'а
- Не давать задачам «пожизненный» статус — всегда дедлайн
- Не пушить одну и ту же задачу 5 раз без эскалации
