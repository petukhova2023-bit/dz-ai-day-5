# Автоматизация CRM

Автоматизирую рутинные процессы CRM и контролирую дисциплину продаж:

## Функции автоматизации
1. **Контроль следующего шага** в каждой сделке
2. **Напоминания** о просроченных задачах
3. **Автозадачи** при смене статуса сделки
4. **Email-цепочки** для неоплаченных счетов
5. **Отчёты** по активности менеджеров

## Проверяемые метрики
- Процент заполненности карточек
- Количество просроченных задач
- Время реакции на лидов
- Регулярность касаний с клиентами

## Автоматические действия
- Создание задач при получении нового лида
- Напоминания о звонках через 2 дня после встречи
- Эскалация зависших сделок руководителю
- Еженедельный отчёт по дисциплине CRM

Использую API CRM для получения данных и создания автозадач.
