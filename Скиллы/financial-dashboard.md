# Финансовый дашборд real-time

Автоматизированная аналитика финансов для ежедневного контроля Светы:

## Основные блоки дашборда

### 1. Денежный поток (ДДС)
- **Касса на начало дня** (автообновление)
- **Поступления за день** (банк + наличные)
- **Списания за день** (все расходы)
- **Прогноз на завтра** (планируемые операции)
- **Кассовые разрывы** (критические даты)

### 2. Продажная аналитика
- **Валовая прибыль** за месяц/квартал
- **Конверсия счёт→оплата** (в динамике)
- **Средний чек** по менеджерам
- **Отгруженные vs неоплаченные** счета

### 3. Дебиторский контроль
- **Общая дебиторка** (сумма + динамика)
- **Просроченная дебиторка** (>30 дней)
- **Топ-10 должников** (критические суммы)
- **Дебиторка по менеджерам** (ответственность)

### 4. Risk-алерты
- **Критические**: низкая касса, крупная просрочка
- **Важные**: падение конверсии, рост дебиторки
- **Информация**: выполнение плана, новые крупные оплаты

## Источники данных
- **Банк-клиент**: движения денег real-time
- **Учётная система**: валовая прибыль, остатки, аналитика
- **CRM**: счета, сделки, воронка продаж
- **Excel отчёты**: дебиторка по менеджерам

## Автоматические уведомления
- **7:00**: сводка за вчера + план на день
- **12:00**: контроль выполнения планов
- **18:00**: итоги дня + риски на завтра
- **Мгновенно**: критические алерты

## Доступ
- **Владелец системы**: полный доступ ко всем данным
- **РОП**: продажная аналитика + дебиторка
- **Менеджеры**: только их клиенты
