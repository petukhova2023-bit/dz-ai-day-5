# qa-testing

## Когда использовать
- Нужно проверить готовность функции.
- Нужно протестировать релиз.
- Нужно собрать тест-кейсы.

## Workflow
1. Прочитать требования и сценарии.
2. Составить smoke-тесты.
3. Добавить edge cases.
4. Проверить результат.
5. Зафиксировать статус и баги.

## Выход
Тест-план, чек-лист, статус проверки.
