# Анализ воронки продаж

Провожу глубокий анализ коммерческих показателей в B2B-направлении:

## Этапы анализа
1. **Воронка продаж**: количество лидов → переговоры → счета → оплаты
2. **Конверсия**: процент перехода между этапами
3. **Дебиторка**: просроченные платежи по менеджерам
4. **Зависшие сделки**: анализ причин зависания
5. **Рекомендации**: конкретные шаги по улучшению

## Выходные данные
- Сводка по конверсии счёт→оплата
- Топ-5 зависших сделок с суммами
- Рейтинг менеджеров по результативности
- План действий на неделю

Использую данные из CRM, финансовой отчётности и беседы с менеджерами.
