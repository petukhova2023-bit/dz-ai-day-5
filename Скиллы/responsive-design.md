# responsive-design

## Когда использовать
- Нужно адаптировать страницу под разные экраны.
- Текст или блоки ломаются на мобильном.
- Нужно проверить layout перед релизом.

## Workflow
1. Проверить ключевые ширины: mobile, tablet, desktop.
2. Найти переполнения и наложения.
3. Исправить сетки, размеры, переносы.
4. Проверить основные состояния.

## Выход
Адаптивный UI без наложений, обрезки и скачков.
