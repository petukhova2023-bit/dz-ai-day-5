# backend-api

## Когда использовать
- Нужно создать API.
- Нужно исправить серверную ошибку.
- Нужно описать контракт frontend/backend.

## Workflow
1. Понять сценарий и данные.
2. Описать endpoint, payload, response, errors.
3. Реализовать или обновить код.
4. Проверить обработку ошибок.
5. Передать контракт frontend и QA.

## Выход
Рабочий API-контракт и реализация.
