# monitoring-observability

## Когда использовать
- Нужно понять, почему система падает.
- Нужно добавить логи или метрики.
- Нужно сделать отчёты о состоянии.

## Workflow
1. Определить критические события.
2. Добавить логи и метрики.
3. Описать red flags.
4. Настроить формат отчёта.

## Выход
Список метрик, логов, алертов и диагностических шагов.
