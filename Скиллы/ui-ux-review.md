# ui-ux-review

## Когда использовать
- Нужно проверить экран перед релизом.
- Пользовательский сценарий непонятен.
- Интерфейс выглядит перегруженным или пустым.

## Workflow
1. Определить главный пользовательский сценарий.
2. Проверить первый экран, иерархию, CTA.
3. Найти лишнее, непонятное, конфликтующее.
4. Дать конкретные правки.

## Выход
Список UX/UI-правок по приоритету.
