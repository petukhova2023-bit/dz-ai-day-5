# deal-closer

Скилл закрытия B2B-сделок в сегменте технического оборудования. Главный фокус — превратить счёт в оплату.

## Когда использовать

- Сделка зависла > 14 дней на стадии «счёт выставлен»
- Клиент молчит после получения КП
- Менеджер не понимает следующий шаг
- Низкая конверсия счёт→оплата у менеджера
- Возражение «дорого» / «нужно подумать» / «согласовываем»

## Диагностика зависшей сделки

### Чек-лист причин зависания

| Причина | Признак | Действие |
|---------|---------|----------|
| **Технический вопрос** | клиент уточняет спецификацию | подключить ПТО, дать аналог |
| **Сравнение с конкурентами** | «у других дешевле» | показать ценность, не скидку |
| **Согласование внутри** | «ждём от руководства» | помочь продать ЛПРу, дать материалы |
| **Деньги** | «оплатим в следующем месяце» | предложить отсрочку, частичную предоплату |
| **Не нужно сейчас** | «проект отложили» | поставить в follow-up на дату возобновления |
| **Холодная сделка** | менеджер не докрутил | вернуться к дожиму, показать срочность |

### Скрипты дожима

**Если клиент молчит 3–5 дней после счёта:**
```
«Имя, добрый день. Мы выставили счёт на <сумма> по объекту <название>.
По нашей логистике, чтобы успеть к вашему сроку <дата>,
оплату нужно получить до <дата минус N дней>.
Когда ориентируетесь оплатить?»
```

**Если возражение «дорого»:**
```
1. Признать: «Понимаю, цена выглядит выше ожидаемой»
2. Спросить: «С чем именно сравниваете?»
3. Показать состав: «Давайте разберём за что именно платите»
4. Дать аналоги: «Можем подобрать аналоги по N пунктам, цена будет ниже на X%»
5. НЕ ДАВАТЬ скидку первым ходом
```

**Если «согласовываем»:**
```
«Понятно. Подскажите:
- кто именно согласует на вашей стороне?
- какие у них вопросы могут быть?
- нужны ли дополнительные материалы для ЛПР?
- когда ожидаете решение?»
```

## Workflow по конкретной сделке

### Шаг 1: Контекст
1. Прочитать карточку сделки (CRM или из задачи)
2. Какая стадия? Что было последним?
3. Сумма, цикл, маржа
4. Кто LPR на стороне клиента

### Шаг 2: Диагностика
1. Применить чек-лист причин
2. Определить вероятную причину зависания
3. Если не ясно — назначить звонок-уточнение

### Шаг 3: Следующий шаг
Сформулировать ОДИН конкретный следующий шаг:
- Не «позвонить и обсудить»
- А «позвонить контактному лицу в среду 15:00, спросить статус согласования у финдиректора»

### Шаг 4: Эскалация
- Если зависла > 30 дней — эскалация Свете (риск дебиторки если уже отгрузили)
- Если LPR не выходит на связь — попросить владельца системы сделать заход через свою сеть
- Если сделка на грани провала — провести совместный звонок с Тимом

## Анализ конверсии менеджера

Если у менеджера низкая конверсия счёт→оплата:
1. Взять последние 20 счетов
2. По каждому — на какой стадии умер
3. Найти паттерн (где именно проседает)
4. Подобрать тренинг под проседание (скрипты, дожим, возражения)
5. Поставить план на 30 дней с контролем

## Антипаттерны

- Не давать скидку при первом возражении «дорого»
- Не отпускать сделку без конкретного follow-up'а
- Не дожимать клиента который сказал твёрдое «нет» — отпустить и вернуться через 3 месяца
- Не работать с клиентом которого не идентифицирован LPR
