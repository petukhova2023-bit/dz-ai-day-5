# database-design

## Когда использовать
- Нужно добавить сущность.
- Нужно изменить структуру данных.
- Нужно понять связи между объектами.

## Workflow
1. Определить сущности и поля.
2. Описать связи.
3. Проверить приватность и ограничения.
4. Подготовить миграцию или схему.
5. Добавить правила в документацию.

## Выход
Схема данных, связи, ограничения, миграции.
