# user-research

## Когда использовать
- Нужно понять пользователя.
- Нужно сформировать гипотезы.
- Нужно проверить боли и мотивацию.

## Workflow
1. Определить сегменты аудитории.
2. Описать боли, желания, страхи.
3. Сформулировать Jobs To Be Done.
4. Передать выводы Product Manager и CMO.

## Выход
Карта аудитории, боли, JTBD, гипотезы.
