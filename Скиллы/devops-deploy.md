# devops-deploy

## Когда использовать
- Нужно запустить проект локально или на сервере.
- Нужно настроить переменные окружения.
- Нужно подготовить деплой.

## Workflow
1. Проверить зависимости и команды запуска.
2. Проверить `.env.example` без секретов.
3. Описать сборку и старт.
4. Проверить логи и ошибки.
5. Зафиксировать инструкцию.

## Выход
Рабочий запуск и инструкция деплоя.
