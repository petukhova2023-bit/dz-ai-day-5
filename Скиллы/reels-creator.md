# reels-creator

Скилл создания сценариев Reels и Shorts для личного бренда эксперта — антикризис, B2B-менеджмент, женское лидерство в реальном секторе.

## Когда использовать

- Запрос «дай 5–10 идей Reels на эту неделю»
- Адаптация поста / выступления в формат короткого видео
- Разбор какой-то конкретной темы в крючок + разворот
- Анализ вирусных видео конкурентов и адаптация механики

## Архетип контента

**Не показываем:**
- Глянец, сторис из самолётов, лайфстайл «успешного успеха»
- Цитаты-обои в духе инфобиз
- Танцы, тренды без смысла

**Показываем:**
- Антикризисные разборы из своей практики
- Сильные тезисы за 30–45 секунд
- Реальные цифры из бизнеса (без конкретики компании)
- Командная динамика, управленческие ошибки и уроки
- Женская сила в реальном секторе

## Структура сильного Reels (45–60 сек)

### Крючок (0–3 сек)
Должен останавливать скролл. Варианты:
- Контр-тезис: «Деньги не приходят к тем, кто работает больше»
- Цифра: «За месяц моя дебиторка выросла на несколько миллионов. Вот что я сделала»
- Вопрос: «Знаете когда менеджер по продажам стоит вам дороже, чем приносит?»
- Признание: «Самая дорогая ошибка в моём бизнесе стоила мне миллионы»

### Контекст (3–10 сек)
Кто, когда, в какой ситуации. Один-два предложения.

### Разворот / разбор (10–40 сек)
- Что было неправильно
- Что я сделала / решила
- Что произошло в результате

### Вывод (40–55 сек)
Сильный тезис. ОДИН. Не «5 правил».

### CTA (55–60 сек, опционально)
- «Сохраняй если знакомо»
- «В комментах напиши столкнулись или нет»
- НЕ «переходи по ссылке в шапке профиля»

## Workflow

### Запрос на N идей
1. Уточнить формат: образовательный / личный / провокация / разбор
2. Уточнить аудиторию: предприниматели / специалисты / ЛПР клиенты
3. Найти 3–5 актуальных тем из текущей повестки владельца системы
4. По каждой — крючок + одно предложение разворота
5. Топ-N выдать в формате ниже

### Output формат

```markdown
# Reels-идеи · <дата>

## 1. <Название>
**Крючок**: <2-3 секунды>
**Разворот**: <одна фраза>
**Вывод**: <ударная мысль>
**Виз. идея**: <статика / в кадре / b-roll>
**Длительность**: ~45 сек
**Хэштеги**: <2-3 максимум>

## 2. ...
```

### Адаптация поста в Reels
1. Найти главную мысль поста
2. Сжать в 1 крючок + 1 разворот + 1 вывод
3. Если поста на 3 разные мысли — разбить на 3 Reels
4. НЕ сохранять авторские формулировки без согласования (правило системы)

## Темы из текущей повестки (банк)

- Антикризис: что делать когда дебиторка съедает кассу
- Команда: как уволить слабого продажника без драмы
- Деньги: почему «оборот» обманывает
- Личное: что я делала когда начинался шторм
- Региональный бизнес без розовых очков
- Женщины-собственники в B2B: реальность

## Антипаттерны

- Не делать Reels без сильного крючка в первые 3 секунды
- Не пихать 5 мыслей в одно видео — одна мысль = одно видео
- Не использовать тренды без релевантности теме
- Не писать сценарий за владельца системы дословно — давать каркас, а не текст
- Не обещать результат «после этого видео клиенты сами придут»
