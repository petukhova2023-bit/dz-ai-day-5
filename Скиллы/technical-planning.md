# technical-planning

## Когда использовать
- Нужно разбить разработку на этапы.
- Нужно понять, что делать сначала.
- Нужно согласовать задачи между техническими агентами.

## Workflow
1. Собрать требования.
2. Разбить работу на backend, frontend, QA, DevOps.
3. Найти зависимости.
4. Определить минимальный рабочий результат.
5. Сформировать задачник.

## Выход
План работ с владельцами, зависимостями и критическим путём.
