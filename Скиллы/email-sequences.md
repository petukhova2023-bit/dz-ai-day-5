# Email-цепочки дожима продаж

Автоматизация дожима сделок через email для роста конверсии счёт→оплата:

## Типы автоматических цепочек

### 1. Цепочка «Неоплаченный счёт»
**Триггер**: Счёт выставлен, 3 дня без оплаты
**Последовательность**:
- День 3: Напоминание о счёте + польза для клиента
- День 7: Уточнение сроков + предложение рассрочки
- День 10: Звонок менеджера + email с вариантами оплаты
- День 14: Руководителю клиента + дедлайн
- День 21: Финальное предупреждение

### 2. Цепочка «Зависшая сделка»
**Триггер**: Сделка в переговорах >30 дней
**Последовательность**:
- Неделя 5: «Что вас останавливает?» + разбор возражений
- Неделя 6: Кейс похожего клиента + результаты
- Неделя 7: Ограниченное предложение + бонусы
- Неделя 8: Альтернативное решение + компромисс

### 3. Цепочка «Холодная база»
**Триггер**: Клиент не покупал >6 месяцев
**Последовательность**:
- Месяц 1: «Как дела на объектах?» + новости рынка
- Месяц 2: Специальное предложение + скидка
- Месяц 3: Приглашение на мероприятие/вебинар

## Персонализация
- Учёт специфики целевого региона и продуктовой ниши
- Привязка к сезонности
- Упоминание конкретных проектов клиента

## Метрики отслеживания
- Open rate по типам писем
- Click-through rate на ключевые CTA
- Конверсия email→звонок→встреча
- ROI по каждой цепочке
