# product-requirements

## Когда использовать
- Нужно сделать ТЗ.
- Нужно описать MVP.
- Нужно уточнить, какие функции обязательны.

## Workflow
1. Сформулировать проблему пользователя.
2. Описать целевую аудиторию.
3. Разделить must-have / should-have / later.
4. Добавить критерии приёмки.
5. Передать техническим агентам.

## Выход
PRD/MVP-описание, сценарии и критерии готовности.
