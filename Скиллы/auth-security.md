# auth-security

## Когда использовать
- Есть логин, роли, личные данные или платежи.
- Нужно проверить доступы.
- Нужно снизить риск утечки.

## Workflow
1. Определить чувствительные данные.
2. Проверить роли и права.
3. Проверить хранение секретов.
4. Описать риски и меры защиты.

## Выход
Security checklist и конкретные исправления.
