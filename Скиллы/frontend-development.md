# frontend-development

## Когда использовать
- Нужно создать или изменить интерфейс.
- Нужно подключить данные к UI.
- Нужно исправить frontend-баг.

## Workflow
1. Изучить текущую структуру приложения.
2. Найти существующие компоненты и стиль.
3. Внести минимально нужные изменения.
4. Проверить адаптив и состояния.
5. Передать QA.

## Выход
Рабочий интерфейс с понятными состояниями и без визуальных поломок.
