# tender-scraper

Поиск, фильтрация и анализ тендеров в B2B-направлении технического оборудования.

## Когда использовать

- Еженедельный мониторинг (каждый понедельник утром)
- Поиск тендеров по конкретному запросу
- Анализ перспективности конкретного лота
- Подготовка отчёта по результативности участия

## Целевые площадки

Основные:
- Площадка госзакупок по 44-ФЗ
- Площадка закупок по 223-ФЗ
- Коммерческие электронные торговые площадки
- Региональные площадки

## Критерии отбора

**Включаем:**
- География: целевые регионы присутствия
- Предмет: профильные категории технического оборудования
- Бюджет: от заданного порога
- Срок исполнения: реальный для нашей логистики (минимум 30 дней)

**Исключаем:**
- Демпинг (НМЦ слишком низкая)
- Требования к лицензиям которых у нас нет
- Слишком короткие сроки (< 14 дней)
- Сложные доп. требования (большой залог, отсутствующие сертификации)

## Workflow

### Поиск тендеров
1. Сформировать запрос с ключевыми словами + регион + диапазон НМЦ
2. WebFetch на каждую площадку или WebSearch с фильтрами
3. Собрать результаты в таблицу
4. Применить критерии отбора
5. Топ-10 → детальный анализ

### Анализ конкретного лота
1. Загрузить ТЗ (WebFetch URL лота)
2. Разобрать спецификацию: что нужно, в каком количестве
3. Оценить можем ли исполнить:
   - Технически (имеется в наличии / можем привезти)
   - По срокам (логистика)
   - По цене (хватает ли маржи)
4. Проверить конкурентов (история площадки, кто обычно участвует)
5. Решение: рекомендуем участвовать / отказаться / на грани

### Output

```markdown
# Тендер: <название>
**Площадка**: <название>
**Номер**: <ID лота>
**НМЦ**: <сумма>
**Срок подачи**: <дата>
**Срок исполнения**: <дата>

## Что нужно
<выжимка из спецификации>

## Наша оценка
- **Технически**: можем / частично / нет
- **Сроки**: реальные / сжатые / невозможные
- **Маржа**: <ожидаемая %>
- **Конкуренция**: высокая / средняя / низкая

## Решение
УЧАСТВОВАТЬ — обоснование
ОТКАЗАТЬСЯ — причины
НА ГРАНИ — что нужно уточнить

## Передать Тиму
<краткий бриф для коммерческой подготовки>
```

## Антипаттерны

- Не подавать заявки без согласования с Тимом и Светой
- Не участвовать в тендерах с сомнительной репутацией заказчика
- Не демпинговать ради объёма — приоритет валовая прибыль
